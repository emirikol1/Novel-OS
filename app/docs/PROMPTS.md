# Prompt Presets

Novel OS lets authors tune the agent system prompts from the app without editing files by hand.

Open **Sidebar -> AI settings -> Agent prompt presets**.

---

## What Can Be Edited

Prompt presets apply to the seven agent system prompts:

| Agent | Used For |
|---|---|
| Architect | Chapter outlines and structural planning |
| Scribe | Draft prose generation |
| Editor | Revision, regeneration, placeholder expansion |
| Continuity Guardian | Validation and continuity reports |
| Lorekeeper | Story-bible and background extraction |
| Archivist | Existing manuscript import and chapter mining |
| Style Curator | Voice and style analysis |

Dynamic task prompts are still generated by code because they include chapter text, StoryState, plot context, mentions, and author instructions.

---

## The Three Variants

Each agent has three selectable variants:

| Variant | Meaning |
|---|---|
| Current default | The shipped file at `agents/<agent>/prompt.md` |
| Recommended | A cleaner Novel OS default focused on practical workflow behavior |
| Custom | User-edited text stored in install config |

Use **Copy recommended into custom** when you want to start from the recommended prompt and tune it.

---

## Safety Guardrails

Several agents must emit machine-readable blocks so Novel OS can parse results back into state.

Examples:

- `[SCRIBE_STATE_UPDATE]`
- `[REVISED_CHAPTER]`
- `[EDITOR_STATE_UPDATE]`
- `[CONTINUITY_REPORT]`
- `[CONTINUITY_STATE_UPDATE]`
- `[CHAPTER_OUTLINE]`
- `[BACKGROUND_STATE_UPDATE]`
- `[IMPORT_STATE_UPDATE]`

When **Custom** is selected, Novel OS appends an immutable output-contract guard for parser-critical agents. This lets authors change voice, priorities, and editorial behavior without accidentally removing the required tags.

Do not use custom prompts to tell agents to ignore output contracts. The parser depends on them.

---

## Global Prefix vs Agent Presets

The **Global system prefix** is prepended to every agent prompt. Use it for broad house rules:

- preferred tense
- forbidden punctuation
- content rating
- genre-wide tone guidance
- local model quirks

Use **Agent prompt presets** when the instruction belongs to one specific role:

- make Scribe more cinematic
- make Editor more aggressive about cutting exposition
- make Guardian stricter about travel time
- make Architect use a specific beat-sheet style

## Storage and Code Paths

| Item | Location |
|---|---|
| Current defaults | `agents/*/prompt.md` |
| Recommended defaults | `core/app_settings.py` |
| Custom prompts | `~/.local/share/novel-os/config/agent_prompts/*.md` |
| Selected variants | `~/.local/share/novel-os/config/app_config.json` |
| Prompt selection | `core/app_settings.py::effective_agent_prompt` |
| Agent calls | `core/llm_client.py::run_agent` |
| UI | `web/src/components/SystemSettingsPanel.tsx` |

Settings are install-wide, not per project.

---

## Recommended Workflow

1. Start with **Current default** until a behavior bothers you.
2. Try **Recommended** for that agent.
3. If you want finer control, copy Recommended into Custom.
4. Change one behavior at a time.
5. Run a small chapter or dry-run style task before relying on the prompt for a long generation.

If generated output stops applying to state, check whether the custom prompt conflicts with the required output contract.
